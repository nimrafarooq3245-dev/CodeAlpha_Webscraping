# Web Scraping Project – E-commerce Products Dataset

## 📌 Project Overview
This project focuses on web scraping to collect structured e-commerce product data from a practice website using Python. The extracted data is organized into a Pandas DataFrame and saved as a CSV file for further analysis.

## 🎯 Objectives
- Extract product information from a website using web scraping techniques.
- Parse HTML content using BeautifulSoup.
- Organize the extracted information into a structured dataset.
- Export the collected data into a CSV file.
- Build practical experience with Python libraries used in data analytics.

## 🛠️ Tools and Technologies
- **Python** – Programming language
- **Requests** – To send HTTP requests and retrieve webpage content
- **BeautifulSoup** – To parse HTML and extract data
- **Pandas** – To organize and manage the dataset
- **Google Colab** – To write and execute Python code

## 📊 Dataset Description
The scraped dataset contains e-commerce product information, including the following fields:

- Product Name
- Vendor
- Category
- Price
- Rating
- Stock
- SKU
- Variants

The extracted data is stored in CSV format for easy access and further analysis.

## ⚙️ Project Workflow
1. Import the required Python libraries.
2. Send an HTTP request to the target webpage using Requests.
3. Parse the HTML content using BeautifulSoup.
4. Extract the required product information.
5. Store the collected data in a Pandas DataFrame.
6. Export the dataset to a CSV file.

## 📁 Project Files
- **Web_Scraping.ipynb** – Jupyter Notebook containing the web scraping code.
- **ecommerce_products_dataset.csv** – CSV file containing the scraped product data.
